# Расширенный тест Strata NVFP4 на .42

Проведён полный профиль [`llm-tests-1`](https://github.com/crowrain/llm-tests-1) на `denis@192.168.1.42`: Ryzen 9 5900X, 128 GiB RAM, две RTX 5060 Ti 16 GiB. Профиль Strata: GPU 1 основная, GPU 0 кэш экспертов, контекст 262144, `--kv int8 --kv-resident 32768`. Endpoint: llama-swap `http://127.0.0.1:8080`, alias `strata-nvfp4`. Набор тестов: commit `df14320dd3ae6ae63f1b34bc031427edb7cb3aaa`.

## Качество

| Категория | Верно / всего |
|---|---:|
| GSM8K | 97/100 |
| ARC-Challenge | 97/100 |
| MMLU | 49/50 |
| JSON-инструкции | 12/12 |
| Поиск в длинном контексте | 4/4 |
| **Итого** | **259/266 (97,37%)** |

Ошибок запросов и обрезанных ответов нет. Медианная скорость генерации по оцениваемым заданиям: **70,2 токена/с**. Время всего прогона с 30 отдельными пробами префилла: **40 мин 44 с**.

Длинный контекст проверен на реальных входах 16 279, 64 834, 129 574 и 182 224 токена: во всех четырёх случаях нужная метка найдена. Время ответа вместе с генерацией: 11,9; 34,5; 70,3 и 100,6 с соответственно. Полные 262 144 токена этим набором не проверяются.

## Префилл

Для каждой длины выполнено три разных холодных запроса и по одному точному повтору каждого. Значения ниже — `backend_fresh_tps` из суммарной телеметрии сервера, вычисленные как свежие токены / время префилла; это не скорость генерации.

| Длина входа | Медиана токенов | Холодный префилл, ток/с | Среднее время холодного запроса |
|---|---:|---:|---:|
| <512 | 62 | 93 | 0,69 с |
| 16K | 16 299 | 1 595 | 10,28 с |
| 64K | 64 855 | 1 998 | 32,52 с |
| 128K | 129 593 | 1 914 | 67,81 с |
| 180K | 182 244 | 1 856 | 98,32 с |

Все повторы распознаны сервером как кэшированные: повторно обрабатывались только несколько свежих токенов. Скорость «прочитанных токенов» на таких повторах нельзя трактовать как скорость вычисления модели.

## Сопоставление с прежним Strata IQ3XXS

Предыдущий отчёт `strata-iq3xxs-4080s` использует те же 266 фикстур, системный промпт и параметры запроса. Он дал 260/266 против 259/266 здесь. Разница в один балл — ARC-Challenge (98/100 против 97/100); GSM8K, MMLU, JSON и длинный контекст совпали по итоговым баллам. Совпадение сумм не означает совпадение каждого ответа: в GSM8K два ответа поменялись местами между верным и неверным.

Медианная генерация прежнего прогона: 88,5 токена/с против 70,2 здесь. Его префилл на 180K: 3 241 против 1 856 токенов/с. Это сравнение **разных моделей/квантований и аппаратных конфигураций** (RTX 4080 SUPER против двух RTX 5060 Ti), поэтому оно не измеряет изолированный эффект NVFP4 или второго GPU.
