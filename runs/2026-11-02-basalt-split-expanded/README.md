# Расширенный тест Basalt IQ3_S на двух RTX 5060 Ti

Полный профиль expanded выполнен 2 ноября 2026 года на Ryzen 9 5900X, 128 ГБ DDR4-3200 и двух RTX 5060 Ti 16 ГБ, Ubuntu 24.04.5. Версия теста — коммит `9443b5a`; исходная версия Basalt — `463d92e8` с локальным изменением в `src/program/generate/prompt_split.cpp`, которое снимает запрет prompt split для форматов экспертов кроме NVFP4. Остальные проверки и оценка стоимости разделения сохранены. GPU 1 (PCIe 4.0 x8) — основная, GPU 0 (PCIe 4.0 x4) — дополнительная; лимит мощности каждой — 180 Вт. Драйвер NVIDIA 615.71.09, CUDA 13.4.

Модель Qwen3.8-Flash-Next GSQ-RCO IQ3_S локально сконвертирована из GGUF в `.basalt` с исходным MTP; это не официальный пакет с дообученным drafter. Контекст 262144, KV int8, `resident-experts`, `expert-cache` и `prefill` — auto, vision выключен. Настройки и данные приведены в [метаданных](run_metadata.json).

Ошибок запросов и усечённых ответов нет. Медианная скорость генерации по оцениваемым заданиям — **150,2 ток/с**. Полный прогон, включая 30 prefill-проб, занял **20:00**. Длинные задания содержали 16279, 64834, 129574 и 182224 входных токена; все четыре контрольные метки найдены. Полный контекст 262144 этим набором не проверяется.

## Prefill

Три холодных запроса и три точных повтора на каждую длину. Скорости в таблице — `backend_fresh_tps`, токены/с; повторное чтение из кэша не считается скоростью вычисления новой последовательности.

| Длина | Медиана входных токенов | Холодный prefill, ток/с |
|---|---:|---:|
| <512 | 62 | 173,7 |
| 16K | 16299 | 2337,8 |
| 64K | 64855 | 3160,3 |
| 128K | 129593 | 3334,8 |
| 180K | 182244 | 3237,5 |

Во всех 15 повторных пробах кэширование подтверждено счётчиками сервера. Журнал движка подтвердил разделение длинных промптов между двумя GPU. Результат относится к данной конфигурации и одному прогону, а не к изолированному влиянию патча на качество.
